每模型

最近动作

GPU 共驻

每张卡可驻留多个模型（睡眠时权重仍留在显存/内存），最多一个 awake。lease 的 fencing token 标识当前唯一写者。

Operation journal

service-manager 的操作日志：每次 wake/sleep/create/repair 的状态与失败原因。

Supervisor

一致性审计

审计会列出全部 pod 并逐个探测 vLLM 的 /is_sleeping，因此只在你点击时运行，不做自动轮询——实验负载期间请勿频繁点击。

Controller 模式

observe 暂停执行（不扩缩、不 hide），决策照常计算——适合在不扰动租户的情况下观察行为。

参数

编辑后需重启 controller 才生效。W（指标窗口）在 R3 前冻结；结构性字段（镜像、权重、tp_size）锁定。
